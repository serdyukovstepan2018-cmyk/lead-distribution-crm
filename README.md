Система распределения лидов (Lead Distribution System)

RESTful API сервис для автоматического распределения входящих обращений между операторами на основе весовых коэффициентов и текущей загрузки.
Описание

Система позволяет:

    Управлять операторами и их максимальной нагрузкой

    Создавать источники обращений (Telegram боты, формы и т.д.)

    Настраивать веса распределения для каждой пары "оператор-источник"

    Автоматически распределять новых лидов между активными операторами

    Отслеживать статистику по обращениям и загрузке операторов

Функциональность
Основные возможности

    Управление операторами: создание, просмотр, активация/деактивация

    Управление источниками: добавление новых каналов поступления лидов

    Гибкая настройка распределения: весовые коэффициенты для каждого источника

    Автоматическое распределение: алгоритм случайного выбора с учетом весов и загрузки

    Статистика: мониторинг текущей загрузки операторов и общего количества обращений
